# 桌面功能使用

重新启动 Tauri 开发应用，让新增 Rust 命令和窗口权限生效。项目启动命令仍为 `pnpm tauri dev`。

## 截图

点击主界面「截图」，或按默认全局快捷键 F1。可在快捷键设置中修改。

在任一显示器上拖动框选区域，然后选择：

- 贴到桌面：创建独立置顶贴图。
- OCR 识别：识别截图，结果显示在当前工作区的 OCR 列表。
- 复制图片：将选区复制到系统剪贴板。

按 Esc 或右键取消截图。第一版选区限定于单个显示器；每个显示器都有框选窗口。采集前短暂隐藏主界面。

## 贴图

按 F1 截图并框选后，按 F3 或 Ctrl+T 直接固定到桌面；也可以按 Enter / Ctrl+C 复制选区，之后在任意应用中按 F3 将剪贴板图片贴到桌面。F1 和 F3 可在快捷键设置中修改。OCR 列表选中图片后仍可点击「贴图选中图片」。

贴图窗口始终置顶，没有标题栏、工具栏、阴影和可见边框，透明背景上只显示图片。直接拖动图片移动，滚轮缩放图片和窗口，按 0 恢复原始比例。截图直接固定时，贴图出现在原选区位置。

右键图片打开操作菜单：复制图片、OCR 并复制文字、恢复原始比例、关闭。Ctrl+C 复制原图；Esc 或双击关闭。OCR 结果同时保存到工作区历史，复制成功的提示短暂显示后消失。便签仍可独立切换置顶。

关闭贴图保留记录，可在「管理贴图与便签」中重新打开。删除贴图不会删除原图；删除原图前必须先删除引用它的贴图。

## 便签

点击「新建便签」，或按默认全局快捷键 Ctrl+Shift+N（macOS 为 Command+Shift+N）。输入自动保存，可选择四种颜色。图钉独立控制是否置顶，默认关闭。

关闭前提交最后草稿，保存失败会显示错误并保留窗口。管理窗口可重新打开或确认删除便签。

## 常驻与退出

关闭主界面会隐藏到托盘，贴图与便签继续存在。托盘提供打开主界面、截图、新建便签和退出；托盘创建的对象属于默认工作区。

从托盘退出时先保存所有便签及贴图状态。下次启动恢复退出前打开的对象；单独关闭的对象保持关闭，管理窗口可以重新打开。

运行中的旧桌面实例需要重启才能加载新命令。浏览器预览只能展示主界面，系统功能需在 Tauri 桌面应用中使用。
